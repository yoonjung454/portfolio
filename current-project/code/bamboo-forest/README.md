# 대나무숲

익명 게시판처럼 보이지 않는, 인터랙티브한 "대나무숲" 웹사이트입니다.
글 목록도, 댓글창도 없습니다 — 대신 마음을 적으면 작은 종이가 되어 숲으로 떨어지고,
잡아 끌거나 던지고, 대나무에 부딪히며 놀 수 있습니다. 구석에 앉은 판다가 그 모습을 구경합니다.

## 특징

- 고민을 적으면 종이 오브젝트가 되어 하늘에서 대나무숲으로 떨어짐 (Matter.js 물리 엔진)
- 마우스/터치로 잡아 끌거나 던질 수 있음, 대나무·바닥·서로에게 부딪히며 튕김
- 대나무에 세게 여러 번 부딪히면 종이가 점점 구겨지고 작아짐 (글자도 결국 안 보이게 됨)
- 생성 후 1분 30초부터 서서히 투명해지다가, 3분이 되면 잎사귀/빛 조각으로 흩어지며
  "이 고민은 숲이 가져갔어요" 문구가 그 자리에 잠깐 표시됨
- 구석에 앉은 판다가 가장 가까운 고민 쪽으로 시선을 옮기며 구경하고,
  고민이 부딪히면 놀라거나(약한 충돌) 넘어졌다 일어나는(강한 충돌) 애니메이션을 보여줌
- 연못, 돌, 풀, 흔들리는 대나무 등으로 작은 게임 공간 같은 분위기
- Supabase에 저장되어, 몇 초 간격으로 다시 불러오는 방식(폴링)으로 다른 방문자의 고민도
  함께 화면에 나타남 (Realtime 구독 없이 동작)
- UI는 우측 하단의 작은 버튼 하나뿐 — 눌러야 입력창이 나타나고, 나머지는 전부 숲 화면

## 폴더 구조

```
bamboo-forest/
  index.html          진입점
  style.css           최소 UI 스타일
  config.js           Supabase URL/anon key (직접 채워야 함)
  js/
    supabaseClient.js Supabase 연동 (미설정 시 로컬 전용 모드로 자동 전환)
    forest.js         물리 엔진 + 캔버스 렌더링 (대나무/판다/연못/종이/파티클)
    main.js           UI 연결, 폴링, 제출 쿨다운
  supabase/
    schema.sql        Supabase에 실행할 테이블 + 보안 정책
```

## 1. Supabase 설정

1. https://supabase.com 에서 무료 계정 생성 후 새 프로젝트를 만듭니다. (리전은 가까운 곳,
   DB 비밀번호는 안전하게 별도 보관)
2. 프로젝트가 생성되면 왼쪽 메뉴에서 **SQL Editor**를 열고, 이 저장소의
   `supabase/schema.sql` 내용 전체를 붙여넣어 실행합니다.
   - `confessions` 테이블을 만들고, RLS(행 단위 보안)를 켜서
     "누구나 등록 가능 / 최근 10분 이내 글만 조회 가능 / 수정·삭제 불가"로 제한합니다.
3. 왼쪽 메뉴 **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사합니다.
4. `config.js` 파일을 열어 두 값을 채워 넣습니다.

```js
window.BAMBOO_FOREST_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxxxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJ...",
};
```

> `config.js`를 그대로 두면(값을 채우지 않으면) 사이트는 "로컬 전용 모드"로 동작합니다 —
> 화면은 정상적으로 작동하지만 새로고침하면 고민이 사라지고, 다른 사람과 공유되지 않습니다.
> 개발 중 미리보기 용도로는 그대로 써도 괜찮습니다.

## 2. 로컬에서 실행하기

이 프로젝트는 빌드 과정이 없는 순수 HTML/CSS/JS이고, ES 모듈을 쓰지 않는 평범한
전역 스크립트로만 되어 있습니다. 그냥 **`index.html`을 더블클릭**해서 열면 됩니다.

로컬 서버(`npx serve .`, `python -m http.server` 등)를 통해 열어도 당연히 잘 동작하지만,
필수는 아닙니다.

## 3. 사용법

- 우측 하단 🍃 버튼을 누르면 입력창이 펼쳐집니다. 마음을 적고 Enter(또는 ➤ 버튼)로 놓아줍니다.
- 화면에 떨어진 종이를 마우스로 잡고 끌거나, 빠르게 움직이다 놓으면 던지듯 날아갑니다.
- 대나무에 세게 여러 번 부딪히면 종이가 점점 작아지고 구겨집니다.
- 판다 근처로 종이를 던지면 판다가 반응합니다 (살짝 부딪히면 놀람, 세게 부딪히면 넘어짐).
- 아무것도 하지 않아도 90초 후부터 서서히 투명해지고, 3분이 되면 사라집니다.

## 참고 사항

- 등록(insert) 후 한 번 숲에 놓인 고민은 누구도(작성자 본인 포함) 수정하거나 지울 수 없습니다
  (RLS에 update/delete 정책이 없기 때문). "숲이 가져간 고민은 되돌릴 수 없다"는 컨셉과 맞춰
  의도적으로 그렇게 설계했습니다.
- `confessions` 테이블은 계속 쌓입니다. 오래된 데이터를 주기적으로 지우고 싶다면
  `schema.sql` 하단에 주석 처리된 `pg_cron` 예시를 참고하세요 (Supabase 플랜에 따라
  지원 여부가 다릅니다).
- 실시간 구독(Realtime) 없이 6초 간격 폴링으로 다른 사람의 글을 가져오기 때문에,
  최대 몇 초 정도의 지연은 자연스러운 동작입니다.
- 배포(Vercel/Netlify 등)가 필요해지면 정적 파일 그대로 올리면 되지만, `config.js`에
  들어가는 anon key는 공개되어도 되는 키입니다(그 자체로는 RLS 정책 밖의 접근이 불가능).
  다만 실제 배포 전에는 원하는 도메인/스팸 방지 정책을 한 번 더 검토하는 것을 권장합니다.
