# Portfolio — 개인 포트폴리오 사이트

전자공학과 3학년 학생이 그동안 진행한 프로젝트와 학습 과정을 정리하기 위해 만든 개인 포트폴리오 사이트다. 회로부터 코드까지 직접 만들어보면서 남긴 기록들을 한곳에 모아두는 **개인 아카이브 + 포트폴리오**로, 결과물뿐 아니라 그 과정에서 부딪힌 문제와 해결 방법도 함께 남기는 것을 목표로 한다.

이 문서는 앞으로 만들 것에 대한 기획서가 아니라, **지금 실제로 배포되어 있는 사이트의 구조와 기능을 정리한 문서**다. 서버·데이터베이스·프레임워크 없이 순수 **HTML + CSS + Vanilla JavaScript**만으로 만들었고, Home의 3D 오브젝트만 예외적으로 Spline이라는 외부 툴에서 만든 씬을 임베드해서 가져온다.

```

│   ├── code/
│   │   ├── day1-signup/           # 실습 코드 (회원가입 폼)
│   │   ├── day3-resume/           # 실습 코드 (이력서 페이지)
│   │   ├── day4-profilecard/      # 실습 코드 (프로필 카드)
│   │   └── notebooks/             # Python 기초 · 조건문/반복문 노트북(.ipynb)

│       └── ...                    # 그 외 날짜별 실습 결과 캡처
```

## 2. 전체 사이트 구조

페이지 이동 없이 아래로 스크롤하면서 섹션을 순서대로 보여주는 **싱글 페이지 구조**다.

```
Navigation Bar
│  Home 화면에서는 어두운 톤의 알약 모양 메뉴들이 화면 중앙에 떠 있다가,
│  스크롤해서 Home을 벗어나면 하나의 밝은 바로 합쳐지며 맨 위에 고정된다.
│
├── 1. Home             — Spline 3D 로봇이 있는 풀스크린 히어로
├── 2. About            — 자기소개 (배경에 로봇이 은은하게 나타났다 사라짐)
├── 3. Current Project  — 진행중인 프로젝트 (피지컬AI 일경험 프로젝트)
├── 4. Projects         — 프로젝트 아카이브 (실제 자료 5건)
├── 5. Skills           — 오각형 능력치 차트
├── 6. Experience       — 세로 원통 다이얼 (교육/대외활동/공모전/수상/기타활동)
└── 7. Contact          — 연락처 (배경에 로켓 로봇)
```

메뉴를 클릭하면 페이지 이동 없이 해당 섹션으로 부드럽게 스크롤 이동하고, 지금 보고 있는 섹션에 맞춰 메뉴 항목이 자동으로 강조된다. Current Project를 Projects Archive 바로 위에 배치해서 "지금 진행 중인 것"과 "이미 마무리한 것"이 자연스럽게 이어지도록 구성했다.

Home~About~Current Project~Archive~Skills~Experience는 옅은 라벤더-그레이 계열 배경이 섹션마다 조금씩 톤을 바꿔가며 이어지다가, Contact에서 다시 어두운 톤으로 마무리되어 Home의 도입부와 수미상관을 이룬다.

## 3. Home

- 중앙의 3D 로봇은 **Spline**에서 만든 씬을 iframe으로 임베드했다. 로봇의 회전/기울어짐 반응은 전부 Spline 씬 자체의 인터랙션이며, 사이트 쪽에서는 별도의 마우스 트래킹 코드를 두지 않았다 (커스텀 CSS 3D tilt를 넣었다가, Spline 자체 인터랙션과 겹쳐서 로봇이 이상하게 기우는 문제가 있어 전부 제거했다).
- 이름, 한 줄 소개(`I build ideas into systems.`), Projects로 이동하는 버튼, 스크롤 유도 표시가 3D 장면 위에 얹혀 있다.
- Home 화면에서만 Navigation이 어두운 알약 모양 메뉴들로 화면 중앙(Projects 버튼과 태그라인 사이 지점, JS로 실측한 위치)에 떠 있고, 마우스를 올리면 커지며, "Home" 링크 자체는 숨겨둔다. 스크롤해서 Home을 벗어나면 하나의 밝은 바로 도킹된다.

## 4. About

- 전자공학과 3학년, 하드웨어·소프트웨어를 함께 다루는 프로젝트에 관심이 많다는 점, 기획력·실행력이 강점이라는 점 등을 짧은 리스트로 소개한다.

## 5. Current Project — 진행중인 프로젝트

지금 진행 중인 **"피지컬AI 일경험 프로젝트"**(청년 피지컬AI 1기 / 미래내일 일경험, 2026.08.04~진행중)를 별도 섹션으로 보여준다. Archive는 "이미 끝난 기록"만 모아두는 공간이라, 아직 끝나지 않은 프로젝트를 그 안에 섞어두면 어색하다고 판단해서 Archive 바로 위에 분리했다.

화면은 카드 하나가 아니라 **4개의 독립된 블록**으로 나뉘어 있다.

1. **설명 카드** — `IN PROGRESS` 배지, 프로젝트명, 기간·참여 기관, 한 줄 소개, 오늘 교육 내용
2. **사진 캐러셀** — 박스 없이 섹션 배경 위에 바로 떠 있는 형태. 여러 장의 사진이 1.8초 간격으로 자동 크로스페이드된다 (08.14 항목은 실제 작업 화면 스크린샷).
3. **관련 자료** — 실제로 만든 실습 코드·문서·캡처로 바로 연결되는 링크 목록. Projects Archive와 같은 스타일의 폴더 아이콘을 쓴다.
4. **진행 로그** — Toss 스타일의 드래그 가능한 타임라인 슬라이더(08.04~08.14, 8개 기록). 바를 움직이면 그 날짜의 내용과 `NEW`/`과거 기록` 배지가 크로스페이드로 바뀌고, **관련 자료 목록도 그 날짜에 해당하는 항목만 필터링**된다. 카드 박스로 감싸지 않고, 지금 보고 있는 항목만 왼쪽 포인트 컬러 선으로 표시한다.

진행 로그와 관련 자료 카드는 각각 배경이 살짝 비치는 반투명 카드였다가, 가독성을 위해 설명 카드와 함께 더 불투명하게 조정했고, 이후 진행 로그는 다시 카드 형태 자체를 없애고 사진처럼 배경 위에 바로 떠 있는 형태로 바꿨다.

## 7. Skills

카드 그리드 대신 **SVG 오각형 레이더(능력치) 차트**로 만들었다. 5개 축은 Programming, Web, Hardware/Embedded, AI/Computer Vision, Tools다.

- 스크롤해서 차트가 화면에 40% 이상 들어오면 `IntersectionObserver`가 감지해서, 중심에서 바깥으로 커지는 동시에 테두리 선이 `stroke-dashoffset` 애니메이션으로 그려지듯 나타난다. 화면을 벗어나면 같은 과정을 거꾸로 재생해서 지워진다.
- 각 꼭짓점에 마우스를 올리거나 키보드로 포커스하면, 그 분야에서 실제로 써본 기술 목록이 말풍선으로 뜬다 (예: Web → HTML · CSS · JavaScript).
- 데이터 값 자체는 일부러 낮게 잡아서, "전문가"가 아니라 실습/프로젝트 과정에서 사용해본 정도라는 뉘앙스를 유지했다.

## 8. Experience

카드 5개를 나열하는 대신, **세로로 회전하는 원통 다이얼(Wheel Selector)** 로 만들었다. 항목은 교육 · 대외활동 · 공모전 · 수상 · 기타 활동이다.

- 화면 중앙에 있는 항목이 가장 크고 진하게, 위/아래로 멀어질수록 `scale`·`opacity`가 줄고 `rotateX`/`translateZ`로 뒤쪽으로 말려 들어가듯 보인다 (perspective 기반 3D).
- 화살표 버튼이나 마우스 휠이 아니라, **마우스로 직접 잡고 위아래로 끄는 드래그**로만 회전한다. 손을 떼면 가장 가까운 항목으로 자연스럽게 스냅된다. 드래그 중에는 커서가 `grab`/`grabbing`으로 바뀌고, 은은하게 맥동하는 `⇕` 아이콘을 둬서 설명 텍스트 없이도 "여기를 끌 수 있다"는 걸 알 수 있게 했다.
- 흐리게 보이는 항목을 클릭해도 그 항목이 바로 중앙으로 온다.
- 오른쪽에는 선택된 항목에 맞는 대표 비주얼(색상 그라디언트 + 이모지)과 상세 정보(제목/기간/설명)가 크로스페이드로 전환된다.

## 9. Contact

- GitHub, Email, Blog로 바로 이동하는 링크 형태. 서버/DB를 쓰지 않기 때문에 문의 내용을 저장하는 Contact Form은 두지 않았다.

## 10. 스크롤 · 인터랙션 애니메이션

대부분의 동적 효과는 **Vanilla JavaScript**만으로 구현했고, 핵심 패턴은 다음과 같다.

- **스크롤 등장(`reveal`)** — 각 섹션 요소에 공통으로 붙는 클래스. `IntersectionObserver`가 화면에 들어오는 걸 감지해서 `is-visible`을 붙이면 CSS `transition`으로 fade/slide-up된다.
- **Navigation 도킹/활성화** — Home 섹션의 가시 비율에 따라 `.navbar`에 `is-docked`를 토글하고, 현재 보이는 섹션에 맞춰 메뉴에 활성 표시를 한다.
- **진행 로그 슬라이더** — `<input type="range">` 기반. 값이 바뀔 때마다 트랙 채움(`--fill` 커스텀 프로퍼티), 눈금 점, 표시 텍스트, 관련 자료 필터링을 함께 갱신하고 160ms 크로스페이드를 준다.
- **Skills 차트 그리기/지우기** — `.skills-radar-wrap`이 화면에 있을 때만 `is-drawn`을 붙이는 토글 방식이라, 들어올 때 그려지고 나갈 때 지워지는 동작이 양방향으로 자연스럽게 재생된다.
- **Experience 드래그** — Pointer Events(`pointerdown/move/up`)로 구현. `setPointerCapture`를 쓰면 이후 이벤트가 실제 클릭한 `<li>`가 아니라 다이얼 전체로 리타깃되는 특성이 있어서, `pointerdown` 시점에 눌린 항목을 미리 기억해뒀다가 클릭 판정에 쓴다.
- **섹션 배경 로봇(About/Contact)** — 하나의 공용 함수(`initSectionBgRobot`)가 섹션의 가시 여부에 따라 이미지에 `is-visible`을 토글한다.

## 11. 기술 스택

### 사용한 기술

- HTML / CSS / JavaScript (Vanilla, 프레임워크 없음)
- Spline — Home 3D 로봇 씬 제작 및 iframe 임베드 (코드를 직접 짜는 라이브러리가 아니라, 완성된 씬을 가져오는 외부 툴)

### 의도적으로 사용하지 않은 것

- 서버 / 백엔드 / 데이터베이스
- React, Vue 등 프론트엔드 프레임워크, 별도 빌드 도구
- Three.js를 직접 코드로 작성하는 방식 (Spline 임베드로 대체)
- 로그인/회원가입, Contact Form 등 서버 저장이 필요한 기능

## 12. 알려진 제한사항 / 남은 작업

- **Contact — Email·Blog 링크가 아직 placeholder**다 (`mailto:example@email.com`, `https://blog-address`). 실제 주소가 정해지면 교체 필요.
- **Experience 상세 정보 미완성** — "교육" 항목만 실제 내용(2026.08, AI·Web·Embedded 교육 과정)이 채워져 있고, 대외활동/공모전/수상/기타활동은 "추가 예정" 상태다.

## 13. 향후 확장 아이디어

이번 범위와는 분리해서, 여유가 생기면 시도해볼 만한 아이디어만 정리해둔다.

- Spline 씬 자체를 더 정교하게 다듬기 (지금은 기본 로봇 모델)
- Experience의 남은 카테고리(대외활동/공모전/수상/기타활동) 실제 내용 채우기
- Contact Form 없이도, 메일 클라이언트를 거치지 않는 간단한 문의 수단 검토
- 프로젝트/진행 로그 데이터를 HTML에 직접 쓰는 대신 별도 JSON으로 분리해서 관리하는 구조
